# Aimee

WordPress plugins for the Aimee companion platform.

- `aimee-engine/` — **Aimee Engine**, a prompt-light conversation engine that runs alongside Aimee Global and takes over the in-app chat turn for enrolled users only. See `aimee-engine/README.md`.

Aimee Global (the platform plugin: pages, billing, gallery, SMS, voice, memory tables) is deployed separately and must be active for Aimee Engine to do anything.
